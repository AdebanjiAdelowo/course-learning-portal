Given a list of integers `items`, return a **new** list containing each distinct value once, in the order of its first appearance.

For example, `[3, 1, 3, 2, 1]` becomes `[3, 1, 2]`.

Your function must not modify the list it is given, and it must run in time proportional to the length of the list. Testing `value in result` on a list for every element is too slow: use a set to remember what has been seen.
