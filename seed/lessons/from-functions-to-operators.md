## One solve, or the whole family?

A PINN represents the solution of **one** problem instance. Change the initial condition or a coefficient and it must be retrained. Many applications need the opposite: thousands of solves for different inputs, as in design optimisation, uncertainty quantification or control.

The object that maps an input function to the solution is an **operator**:

$$
\mathcal{G} : a \mapsto u, \qquad \text{for example}\quad a(x) = \text{permeability field}, \quad u(x) = \text{pressure}.
$$

**Operator learning** approximates $\mathcal{G}$ itself from pairs $\{(a_i, u_i)\}$ generated by a classical solver. Training is expensive; evaluation for a new input is a single forward pass.

| | PINN | Neural operator |
| --- | --- | --- |
| Learns | One solution $u(x, t)$ | The map $a \mapsto u$ |
| Training data | None required | Many solved examples |
| New input | Retrain | One forward pass |
| Main risk | Optimisation failure | Poor generalisation outside the training distribution |

## The model problem: Darcy flow

Steady flow through a porous medium with permeability $a(x)$ is governed by

$$
-\nabla \cdot \left( a(x)\, \nabla u(x) \right) = f(x) \quad \text{in } \Omega = (0, 1)^2, \qquad u = 0 \ \text{on } \partial\Omega .
$$

The map $a \mapsto u$ is nonlinear even though the PDE is linear in $u$. This is the benchmark you will use in the capstone project.

## Why not an ordinary network?

A convolutional network trained on $64 \times 64$ grids learns a map between vectors of that size. Evaluate it at $128 \times 128$ and it has no reason to work. A neural operator is designed so that the same parameters define a consistent map at any resolution: this property is called **discretisation invariance**.

The construction replaces the matrix multiplication of a standard layer with an integral operator:

$$
v_{l+1}(x) = \sigma\!\left( W v_l(x) + \int_\Omega \kappa_\theta(x, y)\, v_l(y)\, \mathrm{d}y \right).
$$

The kernel $\kappa_\theta$ is learned. Different architectures differ in how they parameterise and evaluate this integral.

## DeepONet in one paragraph

DeepONet uses two networks. The **branch** network reads the input function at fixed sensor locations and outputs coefficients $b_k(a)$. The **trunk** network takes a query point and outputs basis functions $t_k(x)$. The prediction is their inner product:

$$
\mathcal{G}_\theta(a)(x) = \sum_{k=1}^{p} b_k(a)\, t_k(x).
$$

```python
import torch
from torch import nn

class DeepONet(nn.Module):
    def __init__(self, n_sensors: int, width: int = 128, p: int = 64):
        super().__init__()
        self.branch = nn.Sequential(nn.Linear(n_sensors, width), nn.GELU(), nn.Linear(width, p))
        self.trunk = nn.Sequential(nn.Linear(2, width), nn.GELU(), nn.Linear(width, p))

    def forward(self, a: torch.Tensor, x: torch.Tensor) -> torch.Tensor:
        # a: (batch, n_sensors), x: (n_points, 2) -> (batch, n_points)
        return self.branch(a) @ self.trunk(x).T
```
